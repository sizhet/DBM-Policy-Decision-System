## 🧩 What is PDS?

PDS is a **control-centric decision architecture** composed of five pillars:

1. **Knowledge Model (Y=f(X))**
2. **State / Trajectory**
3. **Future Candidate Space**
4. **Decision Engine**
5. **Policy System**

It reframes intelligence as:

> **Policy-governed traversal over future space**
